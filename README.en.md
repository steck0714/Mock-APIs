# Mock-APIs (English)

Mock-APIs is a project for developing extended compatibility APIs and original APIs with the help of AI.

## 🌐 Languages

- [English](README.en.md)
- [日本語](README.ja.md)
- [简体中文](README.zh.md)

## 💡 Concept

Mock-APIs studies and verifies existing real-world APIs and standards, while aiming to preserve their compatibility as much as possible and develop independent implementations and extensions.

The project is not intended to simply copy or port existing APIs.

Implementations may differ depending on environmental limitations, security requirements, compatibility considerations, and implementation challenges.

The goal is to create APIs that maintain compatibility while allowing independent implementation and extension for different environments.

AI is used throughout the development process, including specification research, implementation, testing, identifying problems, and improvements, rather than only for code generation.
