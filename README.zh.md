# Mock-APIs (简体中文)

Mock-APIs 是一个利用 AI 开发“扩展型兼容性 API”和“独立 API”的项目。

## 🌐 语言

- [English](README.en.md)
- [日本語](README.ja.md)
- [简体中文](README.zh.md)

## 💡 项目理念

Mock-APIs 会研究和验证现有的实际 API 以及标准规范，在尽可能保持兼容性的同时，进行独立实现和功能扩展。

本项目并不是为了简单复制现有 API，也不是为了将现有 API 原样移植到其他环境。

根据不同环境的限制、安全性要求、兼容性以及实现上的问题，内部实现可能会有所不同。

我们的目标不是简单移植，而是在保持 API 兼容性的同时，实现适用于不同环境的独立实现和扩展。

AI 不仅用于代码生成，也会用于规范研究、实现、测试、发现问题以及改进等整个开发过程。
