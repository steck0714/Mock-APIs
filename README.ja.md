# Mock-APIs (日本語)

Mock-APIsは、AIを活用して「拡張型互換性API」および「独自API」を実装・開発していくプロジェクトです。

## 🌐 言語

- [English](README.en.md)
- [日本語](README.ja.md)
- [简体中文](README.zh.md)

## 💡 コンセプト

Mock-APIsでは、既存の実APIや標準仕様を調査・検証し、その互換性をできる限り維持しながら、独自の実装や拡張を行います。

単純に既存APIをコピーしたり、別の環境へそのまま移植したりすることを目的としていません。

環境ごとの制約、セキュリティ、互換性、実装上の課題などを考慮し、それぞれの環境に適した実装を行います。

重要なのは、単純な移植ではなく、互換性を維持しながら独立した実装や拡張を可能にすることです。

AIはコード生成だけではなく、仕様の調査、実装、テスト、問題の発見、改善など、開発工程全体の補助として活用します。

## 📦 プロジェクト

### Mock-webusb

WebUSBをベースとした拡張型互換性APIです。

#### 実装

- Pyside6-webusb
- fox-webusb

## 📜 ライセンス

Mock-APIsでは、開発者がコードを確認・改変・修正・改善できるよう、MIT Licenseを基本としたオープンな開発を目指します。

各プロジェクトのライセンスをご確認ください。

## ⚠️ 注意事項

AIの支援によって生成されたコードが含まれる場合があります。

そのため、すべての環境や条件で正常に動作することを保証するものではありません。
